# 건강디딤돌 조회·신청 운영 경계

사업장 계획의 `미실시/실시`는 측정 완료의 증거가 아니다. 자동처리는 활성 정기측정 사업장 중 동일 `code/year/period` 측정일지가 없는 행을 대상으로 한다. 직접 요청은 같은 일지가 있더라도 조회 전용으로 실행하며 신청하지 않는다. 거래종료·수시·알 수 없는 상태는 일반 실행에서 제외한다. 기존 신청의 후속 `final_lookup`은 유지한다.

웹 API는 요청 시 실제 target과 일지를 확인하고, 로컬 Worker는 job 실행 및 공단 신청 직전에 다시 확인한다. 최종 신청 전에는 저장된 번호·신청 대표자·담당자 연락처가 job payload와 일치하는지도 확인한다. 확인 실패와 DB 오류는 외부 신청을 중단한다. 완료 화면은 `result_code`로 조회 결과, 신청 대기, 정책 제외, 실패를 구분한다.

운영 반영 전 진행 중 신청과 예약된 `final_lookup`을 확인한다. 진행 중 신청이 끝나면 승인된 동일 커밋의 웹과 깡통컴 Windows Worker를 반영하고 Worker를 재시작한다. Worker 시작 후 대기·실행 큐가 이어지는지 확인하고, 작업 완료 코드와 목록·상세의 상태를 대조한다. 이 문서는 운영 재시작이나 배포를 승인하지 않는다.
