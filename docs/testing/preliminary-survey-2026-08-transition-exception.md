# 2026년 8월 예비조사 전수 재배정 테스트 한시 특례

> **주의: 이 문서는 운영 canonical이 아니다.**  
> 적용 범위: 측정예정일 2026-08-01 ~ 2026-08-31 전수 재배정 테스트  
> 유효기간: 사용자가 예비조사 기능의 운영 전환을 명시적으로 승인하기 전까지  
> 운영 전환 후: 즉시 효력을 잃으며 `docs/business-rules/preliminary-survey.md`의 정상 운영 규칙만 적용한다.

## 1. 목적

운영 전환 직전 2026년 8월 전체 대상에 대해 과거 V2 배정과 찐확정 이력의 영향을 제거한 상태에서 최신 예비조사 canonical이 처음부터 일관되게 배정하는지 검증한다.

이 특례는 **테스트 계산 기준만 변경**한다. 과거 V2 plan, assignment, measurement_journal 등 이력 데이터를 삭제하거나 덮어쓰기 위한 규칙이 아니다.

## 2. 전수 재배정 시 수정 금지 원천

아래 값은 예비조사 섹션에서 읽기 전용 원천이며 전수 재배정 과정에서 수정하지 않는다.

- 코드
- 사업장명
- 구분(`business_type` 등 현재 사업장 분류 원천)
- 측정예정일 및 다일의 실제 측정일 원천
- 측정 참여자
- 보고서 담당자

`measurement_target_business`와 `daily_staff`의 위 원천값은 추천 입력으로만 사용하고, 예비조사 재배정을 이유로 변경하지 않는다.

## 3. 전수 재배정 대상

아래 예비조사 V2 소유 값은 최신 canonical로 처음부터 다시 계산한다.

- 예비조사일
- 예비조사 방식(방문/유선)
- 예비조사자
- 기존업체 유선의 responsible/reviewer 역할
- 실제 측정일별 측정자(공시료 담당자)
- 실제 측정일별 공시료 코드
- 위 재배정 결과에서 파생되는 추천 상태·충돌 사유

## 4. 과거 V2·찐확정 이력의 한시적 취급

이번 2026년 8월 전수 재배정 테스트에서는 기존 V2 plan/assignment와 찐확정(`measurement_journal` 존재 여부)을 **과거 자료로만 취급하고 재배정 계산에서는 무시한다.**

따라서 기존 V2/찐확정 값은 이번 clean-room 추천에서 다음 용도로 사용하지 않는다.

- 기존 plan 보존/minimum-change
- 예비조사일 또는 예비조사자 고정
- 방문/유선 방식 고정
- 공시료 담당자·코드 고정
- capacity 선점
- dependency lock
- 추천 후보 우선순위
- 최종 검수 화면의 재배정 정답값

단, 기존 데이터 자체는 삭제·수정하지 않는다. 필요하면 비교용 과거값으로만 별도 조회한다.

## 5. 적용할 정상 운영 규칙

재배정 계산 자체는 항상 `docs/business-rules/preliminary-survey.md`의 최신 canonical을 따른다.

특히 다음을 집중 검증한다.

- 최초실시: 방문 필수, 측정예정일 기준 working day `-3 ~ -20`
- 기존업체 유선: 경력 hard rule, responsible/reviewer 역할, 날짜 분산
- 측정자(공시료): 실제 측정일별·사업장별 독립 배정 및 동일일 그룹 코드 정규화
- 다일: 예비조사 plan은 공유하되 공시료는 실제 측정일별로 독립 재계산
- H0508: 다일 공시료가 앞 날짜 값을 carry-forward하지 않는지 확인
- H0525: 최초실시 방문 및 날짜 범위 준수 여부 확인
- H0526: 최초실시 방문 필수 여부 확인

## 6. 측정자(공시료) 목록 표시 검수

날짜별 예비조사 목록의 `측정자(공시료)` 칸은 해당 조회일의 assignment를 `이름(코드)`로 표시한다.

예를 들어 같은 실제 측정일에 강종구가 2개 사업장을 맡으면 두 사업장의 코드는 그날 그룹 전체 정규화 결과에 따라 각각 `C`, `CC`가 되어야 한다. 특정 사업장에 `C`를 영구 고정하지 않는다. 하나가 `C`이면 같은 날 같은 담당자의 다른 하나는 `CC`다.

## 7. 종료 조건

사용자가 운영 전환을 승인하면 이 한시 특례는 즉시 종료한다.

운영 전환 후에는 기존 V2/찐확정을 무시하는 clean-room 재배정 규칙을 적용하지 않고, `docs/business-rules/preliminary-survey.md`의 찐확정·repair·보존 규칙을 정상 적용한다.
