- 외부 경로 API를 비활성화했으므로 차량시간 직접 검증은 0건이다.
- 신규 동일 참여자 하루 2건은 0건이어서 차량 60분 규칙을 적용해야 할 실제 묶음은 없다.
- `distance` 18건은 차량시간이 아니라 좌표 간 직선거리 fallback이며, 주로 같은 날 신규 배정과 기존 경력 검토자 후보의 거리 비교에 사용됐다.
- `region` fallback은 0건이다.
- 나머지는 같은 날 비교 대상이 없거나 좌표가 없어 경로 미확인으로 표시했다. 신규 단독 건은 경로 검증이 필요하지 않다.
