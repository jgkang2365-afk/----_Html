## 사용 자산과 호출 조건

- 차량 경로: 기존 `KAKAO_REST_API_KEY`와 `https://apis-navi.kakaomobility.com/v1/directions` 사용. 비밀값은 출력·보고서·Git에 포함하지 않았다.
- 네이버: 지도 표시용 Client ID는 있으나 서버 차량경로 자산은 확인되지 않아 사용하지 않았다.
- 좌표: 추천 계산 가능 81건 중 유효 좌표 78건, 좌표 누락/비정상 3건. 담당자 누락으로 계산 제외된 3건을 포함한 원본 대상 좌표 사전점검은 81/84 유효였다.
- 방향성: 도로 방향·진입 조건상 A→B와 B→A가 달라질 수 있어 방향키를 구분했다.
- 호출 범위: 엔진이 실제 같은 날 신규와 경력 검토자 후보를 비교한 좌표쌍만 호출했다. 84건 전체 조합은 호출하지 않았다.
- 캐시: Dry-run 세션 메모리 캐시와 방향별 좌표쌍 키를 사용했다.

## 이상 여부와 사용자 확인 사항

- 실제 경로 API 결과가 적용된 뒤 추천일 변경 55건, 경력자 변경 14건이 발생했다. 변경 사업장은 위 별도 표에서 확인할 수 있다.
- API 실패 0건은 실제 호출 실패에 한해 fallback 처리됐다.
- 실제 차량시간이 60분을 넘은 비교는 17개 방향이다. 이 중 신규 후보의 공통 참여자 때문에 날짜가 분리된 쌍은 5개이며, 기존 경력 검토자 선택용 비교 10개는 신규 2건 묶음 판정과 구분했다.
- 결과가 업무적으로 이상해 보여도 이번 작업에서는 알고리즘을 수정하지 않았다.
