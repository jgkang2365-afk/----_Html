# 측정 일정 Google Calendar 표시 규칙

버전: v1.0
확정일: 2026-09-03

## 1. 기본 원칙

- Calendar 일정은 **측정일별 실제 측정참여자**를 기준으로 표시한다.
- 공시료 담당자는 예비조사/배정 후단에서 정해질 수 있으므로 Calendar 최초 생성·수정의 표시 기준으로 사용하지 않는다.

## 2. 제목의 측정참여자 순서

제목의 측정 참여자 순서는 공통 canonical [`측정 참여자 표시순서`](measurement-participant-display.md)를 따른다.
Calendar 제목에서 실제 측정참여자가 없으면 `미지정`으로 표시한다.

## 3. 색상 기준

- 완료 전 Calendar 색상은 **제목에서 맨 앞에 표시되는 일자별 대표 측정참여자**의 색상을 사용한다.
- 따라서 보고서 담당자가 실제 측정에 참여하면 보고서 담당자 색상을 사용한다.
- 보고서 담당자가 참여하지 않으면 공통 표시순서의 첫 번째 실제 측정참여자 색상을 사용한다.
- 기존 완료 처리 규칙(K2B 전송 완료 + 전자계산서 발행 완료 또는 사업장 부담금 0원)에 따른 완료 색상은 계속 최우선으로 적용한다.

## 4. 다일 측정

- 다일 측정은 날짜별 `actual_measurer`를 독립적으로 판단한다.
- 동일 사업장이라도 날짜별 실제 참여자가 다르면 제목 순서와 색상이 날짜별로 달라질 수 있다.
- 보고서 담당자가 특정 일자에 참여하지 않는다고 해서 그 일자의 색상을 보고서 담당자 기준으로 강제하지 않는다.

## 5. 동기화

- 측정대상사업장 관리에서 측정일·측정참여자 등 Calendar 원천값이 변경되면 기존 Calendar 이벤트를 갱신하거나, 기존 이벤트가 삭제된 경우 정상 이벤트를 재생성한다.
- 시스템 DB를 원천으로 삼으며 Calendar의 수동 변경값을 시스템 원천값으로 역수입하지 않는다.
