# 측정 참여자 표시순서

측정일별 실제 측정 참여자를 Calendar, 예비조사, 측정일지·요약의 읽기 전용 표시에서 같은 순서로 보여 준다.

1. 해당 날짜의 보고서 담당자가 실제 측정 참여자에 포함되면 그 담당자를 맨 앞에 표시한다. 나머지 참여자는 원래 입력 순서를 유지한다.
2. 보고서 담당자가 참여하지 않으면 실제 참여자를 `한기문 → 이주형 → 강종구 → 고유빈 → 김민영` 순으로 표시한다. 이 우선순위 밖 인원은 뒤에 두고, 서로 간에는 원래 입력 순서를 유지한다.
3. 표시할 때 중복 이름과 불필요한 공백을 제거한다. legacy 표시 sentinel `-`은 사람 이름이 아니라 빈값으로 정규화한다. 보고서 담당자가 참여하지 않는 경우 참여자 목록에 새로 추가하지 않는다.
4. 정렬은 표시 전용이다. `collaborators`, `daily_staff`, `actual_measurer` 등 원천값과 저장 배열 순서는 변경하지 않는다.

참여자가 없을 때의 문구와 이름 사이 구분자는 각 화면의 기존 표현을 따른다. Calendar 제목은 `미지정`, 예비조사 화면은 `-`를 사용한다.
