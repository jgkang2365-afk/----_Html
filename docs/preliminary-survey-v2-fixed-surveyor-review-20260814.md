## 실제 저장을 위해 필요한 코드 수정

**코드 수정이 필요하다.** 현재 `recommendAndPersistV2`는 참가자를 다시 동적으로 선정하므로 이번 40건에 그대로 사용하면 기존 조사자 고정 정책을 보장하지 못한다.

최소 수정 후보:

1. `lib/preliminary-survey-v2/service.ts`: 기존 `preliminary_survey.preliminary_surveyor`를 잠금 participant로 읽는 날짜 전용 계산 함수를 추가하고 자동추천 함수와 분리한다.
2. `lib/preliminary-survey-v2/manual-validation.ts`: 고정 legacy participant 정책에서 전원 availability·날짜·수용량·경로를 검증하되, 참가자 자동 교체는 하지 않는 검증 모드를 추가한다.
3. 저장 API/RPC 호출부: 승인된 고정 participant/date만 저장하고 `source_responsible_user_id`는 측정대상 원본 FK snapshot으로 유지한다.
4. 기존 participant에 보고서 담당자가 없거나 현재 경력 규칙과 다른 경우 사용자 승인 evidence를 별도로 저장한다.

이번 단계에서는 위 코드를 수정하지 않았다.
